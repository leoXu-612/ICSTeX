# ICSTeX 2.1.0-beta.5 — 结构写作与表格体验

Git 标签：`v2.1.0-beta.5`。macOS Apple Silicon（arm64）DMG/ZIP。公开状态以 GitHub Release 为准。

## 变化

- 结构与源码是同一份 `.tex` 的两种视图，共用保存与撤销；常见块可添加、删除、移动及嵌套。
- 路径按文件、章节和块类型分段，末级不再显示正文或表格摘要；窄窗保留完整提示和读屏文字。
- 正文可在工作区换行编辑；普通表格可直接改单元格、行列、对齐、线条、题注、标签与浮动位置。
- 收紧表格按钮和字段；编译活动条提供轻量反馈，遵循减少动态效果，不显示虚假的完成百分比。
- 整合已验收的工作台分区、面板比例记忆、自动导出状态和四步独立写作练习。
- 不重写未知 LaTeX，不改 PREVIEW/FINAL、文件保存、外部冲突与提交保护规则。

## 更新与验证边界

Beta 3/4 用户可在“ICSTeX → 软件更新…”中检查，或启用自动检查后等待提示。序号 210005
高于 Beta 4 的 210004；下载与保存退出安装仍需用户确认，没有静默安装或自动回滚。

普通旧手动版需先安装带更新器的版本。包与 appcast 使用原 Ed25519 密钥；Apple 应用
签名仍为 ad-hoc，未 Developer ID 签名或公证。本次没有 Windows 或 Intel Mac 新包。

已完成本机原生独立示例、冻结源码完整检查及包内容/签名核验。协作者异机的自动发现、
下载、安装与重启仍需实际验收；不把签名和下载校验当成异机安装已经通过。

复杂表格及 LaTeX 仍保留代码入口。应用不捆绑 LaTeX 发行版或 OCR 模型；重要文稿请独立备份。
