# ICSTeX 2.1.0-beta.3 — 应用内更新与安装保护

发布日期：2026-09-15。Git 标签：`v2.1.0-beta.3`。
本次提供 macOS Apple Silicon（arm64）DMG/ZIP。

## 变化

- 安装包包含固定 Sparkle 2.9.6、更新源和签名公钥，可检查新版并在确认后下载、保存退出、安装和重启。
- 自动检查默认关闭；开启后启动延后检查，运行期间每天复查。下载和安装仍需用户确认。
- 新增安装期共享租约和临时原生协调进程。主程序退出后仍保护安装，迟启动的实例不能进入。
- 协调进程被中断时，持久记录继续保护；准确安装进程结束且应用完整性通过后才恢复启动。不把超时当成安装结束。
- 保留 Beta 2 的写作响应、快速预览、PDF 生命周期和界面修复；本次不改编译核心或增加常驻服务。

## 安装

旧 Beta 1/Beta 2 手动包需先手动安装本版一次，然后使用“ICSTeX → 软件更新…”。
首次安装说明、恢复方式和边界见 `INSTALLATION.md` 与 `KNOWN_LIMITATIONS.md`。

本包未 Developer ID 签名或 Apple 公证，不提供新的 Windows/Intel Mac 包，也不承诺自动回滚。更新包和清单使用独立 Ed25519 签名。旧标签、安装包和备份保持不变。
