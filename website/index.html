公式输入

边看公式，边改 LaTeX

公式编辑器同时显示排版结果和 LaTeX 源码。点“插入”后才会写进文档；如果改错，可以一次撤销。

∫01 x² dx = ⅓ \int_0^1 x^2\,dx = \frac{1}{3}

公式预览 / LaTeX 源码

图片转公式（可选）

从图片识别公式，确认后再插入

安装 pix2tex 后，可以框选图片里的公式并转换成 LaTeX。识别在本机完成，结果会先交给你检查，不会直接改动文档。

图片框选公式 检查核对公式 LaTeX插入文档

项目工作区

源码、PDF 和项目结构放在同一个窗口

写长文档时，可以一边编辑源码、一边看 PDF，并用 Block 控制台管理章节、表格、图片和页面布局。界面可以在 90% 到 150% 之间缩放。

文件与隐私

你的论文默认留在自己的电脑里

不会自动上传
ICSTeX 不会自行上传你的 .tex、PDF、日志或截图。
编译结果不会混淆
如果本次编译失败，界面会把旧 PDF 标出来，不会把它当成最新结果。
联网前由你确认
只有你主动查询 DOI 或 arXiv 信息时，应用才会连接网络。
