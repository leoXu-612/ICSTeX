# ICSTeX 2.1.0-beta.3 — 已知限制

- 这是 macOS Apple Silicon（arm64）Beta，不是正式稳定版；未验收全部 macOS 版本和安装权限布局。
- 使用 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证。更新包和更新清单的 Ed25519 签名不等于 Apple 公证。
- 旧手动版须先手动安装本版一次。自动检查默认关闭，更新源和公钥固定，不提供运行时换源、差分更新或 Windows 自动更新。
- 检查/更新会阻止冲突实例进入；已有多进程实例须先退出。普通多窗口仍在同一应用进程内工作。
- 安装中断后先确认安装进程结束和应用完整性；交接状态未知时可能需要重启 Mac。没有自动回滚，完整性失败须使用可信旧包人工恢复。
- 安装租约针对使用同一协议的应用入口，不是防御有本机写权限的恶意用户的安全边界；不追溯保护旧手动版。
- 本次没有新的 Windows、Windows x64 或 Intel Mac 安装包。历史 Windows ARM64 包只完成有限验收。
- LaTeX 发行版和可选 OCR 组件不包含在安装包内，公式识别结果仍须人工核对。
- 保留已有性能/PDF/UI修复，但不声称全部历史原生崩溃已归因；输入法候选、VoiceOver 和全部纯键盘路径未全面验收。
- 快速预览与正式导出分开，正式导出仍需当前版本完整编译。性能取决于文稿和工具链。
- 打包内容以 `BUILD_RECEIPT.json` 为准。独立 MCP/OCR worker 等源码模块并未全部打包，本次不提供网络 MCP 服务。
- 应用备份不等于文稿备份，请独立备份重要项目。
