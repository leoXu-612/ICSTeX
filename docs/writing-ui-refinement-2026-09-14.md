# 普通写作界面：六项痛点优化

本轮基于当前界面和用户已确认的六项痛点直接实施，不改品牌方向、不引入新功能或动效。
源码/完整回归/安装身份以`PROJECT_STATE.md`为准；原始截图与测试收据在任务证据根
`ui-painpoints-20260914/`。原生验收由agent在独立合成项目中进行，学生文稿不修改。

| 原问题 | 实际改动 |
| --- | --- |
| 空PDF占半屏，正文频繁换行 | 宽窗口未编译时预览区为窄提示栏；已有PDF后恢复原分栏比例，窄窗口仍可切换编辑/预览 |
| 大橙色按钮旁边是一排小图标 | 常用动作显示图标+短标签，保持正式编译与停止语义；自动编译开关和文字随UI缩放 |
| 横向标题条太多 | 普通源码项目状态合入工具栏同一行；移除PDF重复标题和成功加载的重复提示；Block保留独立状态行 |
| 正文/辅助信息尺度失衡 | 保留用户编辑器字号设置，注释改为正体；工具栏、开关、底栏控制台入口采用一致的字级，PDF提示按缩放显示 |
| 未编译状态像错误 | 不显示1/0及整排禁用工具；明确提示先编译，并提供“编译并显示PDF”按钮 |
| 底部空控制台占空间 | 收起时连容器一起隐藏；通过底栏文字按钮展开，保留日志内容、显式展开偏好和错误定位入口 |

“编译并显示PDF”直接触发原有正式编译QAction：包括首次授权、保存、缺工具提示和
原图FINAL路径，不实现第二条编译通道。文档有页后才展示导航工具；过期/失败说明
沿用原状态。编译核心、保存/依赖防抖、字节身份和上轮PDF渲染队列/寿命修复不变。

## 边界与保留记录

- 用户显式展开控制台的偏好仍保留；本轮没有强行覆盖用户编辑器字号。
- 初始样式漏定义toolbar字级导致的启动失败`after-r1`保留，已在执行前补齐派生值。
  旧测试的IconOnly、1/0预期随新设计更新；元数据模拟补pageCount返回值，没有通过
  给产品代码吞异常来通过检查。`focused-first.log`和`writing-tests.log`保留原失败。
- 首轮完整检查只有旧Smoke用例要求未编译PDF至少360宽而失败，与新窄提示栏目标冲突。
  已改为检查正文更宽、空状态主动作完整可见、禁用工具隐藏，并保留原黑块/重叠/窗口
  尺寸检查；专项0.817s通过，产品源码不变。最终preflight的完整通过收据保留在
  `preflight-final/`，没有把首轮失败抹掉。
- 不上传文稿/截图到设计服务，不生成替代性图像，不增加主题框架或额外后台任务。
- 本轮没有重跑旧的IME、VoiceOver、完整多窗口性能矩阵，也不将本轮改动称为这些
  延期项目通过。最终交付是本机Qt应用，不是网页原型或公开发布。
