\section{结构化公式}
在公式编辑器（可视化模式）中输入：
\[
\frac{x^2+1}{\sqrt{y}}
\]

\section{图片识别（可选本地组件）}
打开公式编辑器，点击“图片识别…”，导入公式截图，核对后应用。
例如来自真实论文的 Attention 公式：
\[
\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

\section{批量识别}

“重试此项 / 查看错误 / 从批次移除”，失败项不会静默跳过。
