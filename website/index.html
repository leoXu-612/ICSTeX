ICSTeX 把源码、编译、PDF、公式和项目状态放到同一条可核验的工作流中。论文、日志与截图默认不会离开你的设备。

A RELEASE SHOULD EXPLAIN ITSELF

不是又一个云端编辑器，而是一条清楚的交付路径。

01 / LOCAL

本地优先

项目文件和编译默认留在你的设备；联网元数据查询必须由你主动触发。

02 / PROOF

结果可追溯

编译根、源码版本与 PDF freshness 有明确边界；失败不会伪装成最新 PDF。

03 / NEXT STEP

学生可理解

中文优先的错误信息、环境检查和项目入口，帮助你定位下一步，而不是隐藏复杂度。

2.1 BETA 1 · FORMULA INTELLIGENCE

把结构化写作中最容易失控的部分，带回同一个工作台。

每项功能都保留 LaTeX 源码的可见性与最终确认权。

FORMULA EDITOR 2.0

二维公式输入，源码仍是唯一真值。

在可视结构与 LaTeX 双视图之间工作；确认后只写回一次，支持 Undo / Redo。

∫01 x² dx = ⅓ \int_0^1 x^2\,dx = \frac{1}{3}

OPTIONAL LOCAL OCR

从公式图片到可复核的 LaTeX。

pix2tex 运行时可选安装，在本地识别。ROI、批量队列和逐项重试让每一步可控。

IMAGEREVIEWLaTeX

RESPONSIVE UI SCALE

缩放界面，不缩小判断力。

90–150% UI Scale 与窄窗口适配，保留源码、PDF 和编译控制的清晰层级。

ONE RELIABLE PATH

  1. 01source.tex写作与保存
  2. 02local build本地编译
  3. 03proof.pdf核对 PDF
  4. 04export正式导出

PREVIEW IS NOT DELIVERY

预览可以快，交付必须真。

快速图片预览与最终输出使用隔离路径。手动编译和导出始终以原始图片和当前源码为准，避免把临时预览误当成正式成果。
