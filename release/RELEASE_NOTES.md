# ICSTeX 2.1.0-beta.4 — 写作与公式体验更新

发布日期：2026-09-20。Git 标签：`v2.1.0-beta.4`。macOS Apple Silicon（arm64）DMG/ZIP。

## 变化

- 公式方向键更准确地进入上下标、分子分母与运算符上下限；扩大显示留白，修正测量与绘制字号不一致，保留源码与撤销记录。
- 最新快速预览支持源码/PDF 双向定位，反向定位高亮目标源码行，不额外要求正式编译。
- 独立写作练习、图文教程和模板静态预览帮助完成第一份 PDF；保存、PDF 更新与旧预览状态分别显示。
- 工程 ZIP 导出整理项目内源码、图片、表格和参考文献，便于迁移；项目检查点、恢复与固定交付流程继续保护原件。
- 整合主线编译进程树取消、跨平台文件和路径隐私修复，保留此前自动预览、PDF 生命周期及局部去重改进。
- 手写识别试验未达质量门槛，不提供入口或捆绑模型；已有图片 OCR 仍为独立可选组件。

## 自动更新验收

已安装 Beta 3 的 Mac 用户可在“ICSTeX → 软件更新…”中检查，或在已开启自动检查时重启应用等待提示。自动检查不是静默安装：下载、保存退出、安装重启仍需确认。更新序号为 210004，高于 Beta 3 的 210003。

旧手动版需要先从官网手动安装一次。协作者的异机自动发现、下载、安装与重启结果仍需实际确认，不把签名/HTTP 检查当作这些步骤已经通过。

本包使用 ad-hoc 签名，未经 Apple Developer ID 签名或公证；更新包和清单使用现有 Ed25519 密钥。没有新的 Windows/Intel Mac 安装包；不捆绑 LaTeX 或 OCR 模型。重要项目请保留独立备份；没有自动回滚。
