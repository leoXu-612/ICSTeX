# 本地公式识别（pix2tex）使用指引

## 是什么

ICSTeX 的可选本地公式 OCR：把公式图片（文件或剪贴板）识别为 LaTeX 候选，进入公式编辑器
人工核对后写入公式。全程本机运行，无云端、无 MCP。

## 安装（可选）

1. 需要独立 Python 3.10/3.11 环境与网络；
2. 安装完成后在公式编辑器点“图片识别…”；缺少环境或模型时会提示，不能开始识别；
3. 模型权重采用 CC BY-NC-SA 许可，见
   [第三方声明](../packaging/optional/pix2tex/THIRD_PARTY_NOTICE.md)。

未安装时：公式编辑器、公式 Block、编译、PDF 全部照常工作。

## 使用

1. 打开公式编辑器（编辑 → 编辑公式，或 Block 工作区 → 公式 → 编辑公式…）；
2. 点“图片识别…”，添加图片文件或从剪贴板添加，再点击“开始识别”；
3. 等待本地识别（首次需加载模型）；
4. 在“公式识别预览”中**人工核对并修改**候选；
5. 点“应用候选公式”→ 进入可视化编辑器继续修正 → “应用”写回公式。

当前不提供鼠标手写识别：本地试验未达到质量要求，开发入口已撤回，未进入安装包。
原有图片 OCR 不变；安全检查通过不代表识别正确，仍需人工核对。

## 安全

- OCR 候选经安全检查（危险命令/路径/超长被拒绝或降级）；
- 未确认前不修改项目、不编译；
- 识别过程不修改系统剪贴板。
