01 / 开始使用

安装与环境检查

01

下载对应平台

前往下载区，macOS 选择 Apple Silicon；Windows 只有 ARM64 包可用。

02

准备 LaTeX

ICSTeX 不附带 LaTeX。macOS 安装 MacTeX 或 BasicTeX；Windows 安装 MiKTeX 或 TeX Live。

03

运行环境医生

打开应用后，在“帮助 → 环境医生”检查 latexmk、编译器和 texcount。

首次打开 macOS 未公证应用时，需要在系统设置中确认；Windows ARM64 Beta 可能显示 SmartScreen 提示。

阅读完整安装说明 →

02 / 写作流程

先打开项目，再让源码和 PDF 对照起来

  1. 新建或打开项目。可以从模板新建，也可以打开已有的 .tex 文件或项目文件夹。
  2. 编辑源码。LaTeX 源文件是项目的可复制、可检查的事实来源；保存不会移动光标或滚动位置。
  3. 编译并核对。自动预览适合快速查看，正式“编译”用于生成可提交的 PDF。
  4. 检查再导出。确认 PDF 与当前源码一致后，从“文件 → 导出 PDF”生成最终文件。
遇到错误时

先看底部“错误”标签或“帮助 → 环境医生”。编译失败时，上一份成功 PDF 会被标记为旧结果，不会冒充最新版本。

03 / Formula Editor

用结构输入公式，确认后再写回文档

适合什么情况

需要输入分式、根号、上下标、求和或积分等结构化公式时使用。

如何打开

在源码中选中完整公式，选择“编辑 → 编辑公式”；公式 Block 也可以打开同一个编辑器。

基本操作

  1. 在可视化画布中插入或移动结构。
  2. 需要时切换到源码模式，直接修正 LaTeX。
  3. 点击“应用”才会一次写回；取消则不改项目。
快捷输入/ 生成分式，^/_ 生成上下标，sqrt/alpha 可转换为常用结构。
安全边界公式从受管理的结构重新生成；无法解析时保留源码模式，不会静默丢弃原内容。
撤销一次“应用”对应一次项目修改，可以使用 Undo / Redo。

可视化编辑器不是 PDF 正确性的替代品。重要公式仍应正式编译并检查输出。

05 / 输出结果

区分快速预览和正式 PDF

自动预览
适合边写边看，使用隔离的快速路径；打开项目后，首次手动 Compile 前不会自动启动外部编译。
正式编译
使用原图和完整项目重新编译，是导出 PDF 前应执行的步骤。
SyncTeX
双击 PDF 或使用同步操作，在源码与 PDF 之间定位。
导出
“文件 → 导出 PDF”会确认当前源码已保存，并只接受当前版本的正式 PDF。

如果编译失败，请先处理错误再导出；不要把旧 PDF 当作本次结果。

06 / 结构化项目

在 Block 工作区管理章节、表格和布局

从哪里打开

选择“Block → 打开 Block 项目到工作区…”，再选项目目录。Block 生成的 main.tex 仍然是合法的 LaTeX。

一次完整操作

  1. 选择或新建 Block。
  2. 在布局、表格或公式页编辑。
  3. 点击“生成并编译 PDF”。
  4. 在诊断面板处理错误，再导出 PDF 或可移植包。

最后检查

常见问题

为什么自动预览和正式 PDF 不一样？

自动预览优先速度，正式编译使用完整资源。提交前请以正式编译后的 PDF 为准。

修改 UI Scale 会影响文档吗？

不会。UI Scale 只改变应用界面，不写入项目，也不改变 LaTeX 或 PDF 样式。

没有 pix2tex 可以使用公式编辑器吗？

可以。pix2tex 只是可选的图片识别组件，公式编辑器、Block、编译和 PDF 不依赖它。

Windows ARM64 版本可以在普通 Windows 电脑上运行吗？

不可以。Intel/AMD 电脑通常是 x64；当前 x64 ZIP 和安装程序尚未提供。
